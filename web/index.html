Minecraft Java Edition · 1.7.2 ↔ 26.3

Move any resource pack to any version.

packconv upgrades and downgrades resource packs across twelve years of format changes: renamed textures, sliced sprite sheets, new model formats and pack.mcmeta rules. It runs entirely in your browser. Your pack is never uploaded.

Repair re-encodes files that older versions tolerated but newer ones reject: odd PNG encodings, JSON with comments or trailing commas, broken animations. The pack version stays the same.

    Warnings

      Both directions

      Every format change is an upgrade/downgrade pair, so a 26.3 pack can go back to 1.8.9 and an old PvP pack can go forward.

      Private by design

      The converter is Rust compiled to WebAssembly and runs in a worker thread on your machine. Nothing leaves the page.

      ZIP and RAR

      Archives are unpacked in memory, including RAR 1.3, 4 and 5, with no external tools or C dependencies.

      Honest reports

      Anything that cannot be carried over exactly, like version-bound shaders, is listed as a warning instead of silently dropped.

      Mods pass through

      Only vanilla assets are touched. Mod namespaces, OptiFine and MCPatcher folders are kept byte for byte.

      Also a server

      The same core powers an HTTP microservice (axum) with job limits, queueing and timeouts for small hosts.

      Built with Rust, wasm-bindgen and plain HTML. Not affiliated with Mojang or Microsoft.
